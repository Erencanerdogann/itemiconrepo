## ⚙️ TAG NAME NASIL KULLANILIR?

Tag Name itemine **sağ tıklayarak** aşağıdaki ayar penceresini açabilirsiniz.

![SexyKO Tag Name Sistemi](resim/02_94ec7c91.png)

Bu bölümden karakterinizin üzerinde görünmesini istediğiniz Tag Name'i belirleyebilirsiniz.

Sistem oldukça basit çalışır:

**1️⃣ Tag Name itemine sağ tıklayın**

**2️⃣ Açılan pencereden isminizi belirleyin**

**3️⃣ Renk ayarınızı yapın**

**4️⃣ Kaydedip aktif edin**

---

## 🎨 RGB RENK SİSTEMİ

Tag Name'inizi sadece yazı olarak değil, **RGB renk sistemi** üzerinden istediğiniz renkte kullanabilirsiniz.

RGB değerlerini değiştirerek:

- kırmızı,

- mavi,

- yeşil,

- mor,

- sarı,

- veya kendi özel renk tonunuzu

oluşturabilirsiniz.

Bu sayede karakterinizin üzerindeki Tag Name tamamen size özel bir görünüm kazanır.

---

## 👤 KARAKTER ÜZERİNDE NASIL GÖRÜNÜR?

Ayarladığınız Tag Name, karakterinizin üzerinde doğrudan görüntülenir.

![SexyKO Tag Name Karakter Görünümü](resim/03_cfb7425a.png)

Böylece oyuncular karakterinizi gördüğünde seçtiğiniz özel tag / isim de karakterinizle birlikte görünür.

Bu sistem özellikle karakterini daha özgün ve dikkat çekici hale getirmek isteyen oyuncular için hazırlanmıştır.

---

## ✅ KISACASI

SexyKO Tag Name sistemi sayesinde:

- iteme **sağ tıklayarak** sistemi açabilirsiniz,

- karakteriniz için özel bir Tag Name belirleyebilirsiniz,

- RGB sistemiyle istediğiniz rengi oluşturabilirsiniz,

- seçtiğiniz Tag Name'i karakterinizin üzerinde gösterebilirsiniz.
